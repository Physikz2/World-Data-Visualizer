# 🌍 World Data Visualizer

An interactive, single-page data dashboard built with Python and Dash. Select a metric such as population, GDP per capita, or life expectancy, choose a year, and generate a colorful world map in seconds.

---

## 🌐 Live Preview

The GitHub Pages landing page shows a dashboard-style preview, but the full interactive map requires running the app locally with Python.

---

## 📊 Features

- Dashboard-style landing page preview for the app
- Local Python Dash app for the full interactive world map
- Population, GDP per capita, and life expectancy metrics
- Year selection from 1960 to 2026
- World Bank data loaded dynamically when you click Generate

---

## 🛠️ Tech Stack

- Python 3.x
- Dash (by Plotly)
- Plotly Express
- World Bank API data
- HTML and CSS for the public landing page

---

## 🚀 How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/Physikz2/World-Data-Visualizer.git
cd World-Data-Visualizer
```

### 2. Install dependencies
```bash
pip install dash plotly pandas pandas_datareader
```

### 3. Run the app
```bash
python maps_generator.py
```

Then open your browser at:

http://127.0.0.1:8050
