# 🌍 World Data Visualizer

An interactive, single-page data dashboard built with Python and Dash. Select a metric such as population, GDP per capita, or life expectancy, choose a year, and generate a colorful world map in seconds.

---

## 🌐 Live Site

Visit the mini website here:

https://physikz2.github.io/World-Data-Visualizer/

---

## 📊 Features

- Three interactive map views for population, GDP per capita, and life expectancy
- Dynamic year selection from 1960 to 2026
- World Bank data integration for rich global insights
- A polished landing page that introduces the project and links to the GitHub repository

---

## 🛠️ Tech Stack

- Python 3.x
- Dash (by Plotly)
- Plotly Express
- World Bank API data
- HTML and CSS for the public landing page

---

## 🚀 How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/Physikz2/World-Data-Visualizer.git
cd World-Data-Visualizer
```

### 2. Install dependencies
```bash
pip install dash plotly pandas pandas_datareader
```

### 3. Run the app
```bash
python maps_generator.py
```

Then open your browser to the local Dash URL shown in the terminal.
