What this project does

World Data Visualizer turns public development indicators into a sleek dashboard that lets users explore international data in a visual, accessible way.

Three metrics

Switch between population, GDP per capita, and life expectancy with a single click.

Interactive maps

Hover over countries to inspect exact values and compare regions at a glance.

Fast setup

Run it locally in minutes and start exploring data from the World Bank API.

Built for storytelling

The experience is designed as a mini website that introduces the project clearly, showcases its purpose, and gives visitors a simple path to learn more or run the app themselves.

Quick start

  • Clone the repository
  • Install the Python dependencies
  • Run the Dash app locally
